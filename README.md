## ✨ Overview

**AURUM** is a meticulously designed, single-page corporate website template engineered for consulting firms, technology companies, and professional service organizations. It combines a refined **dark navy & gold** aesthetic with modern web standards to deliver a memorable, trust-building digital presence.

Every element — from the animated hero orbit to the counter animations on scroll — has been crafted to convey **credibility, sophistication, and technical excellence**.

> **Design Philosophy:** *"Luxury is in the details."* Every pixel, every transition, and every micro-interaction has been intentionally designed to elevate the user's perception of the brand.

---

## 🎯 Key Features

### 🎨 Design & Aesthetics
- **Luxury Dark Theme** — Deep navy backdrop accented with a refined gold (`#c9a96a`) palette
- **22+ Carefully Composed Sections** — A complete, narrative-driven web experience
- **Glassmorphism & Subtle Depth** — Modern visual language with layered shadows
- **Custom Typography** — Vazirmatn font optimized for Persian/Arabic readability
- **Animated Hero Orbit** — Multi-layered orbiting graphics that communicate motion & innovation
- **Micro-interactions** — Hover states, transitions, and reveals throughout

### ⚙️ Interactive Functionality
- **Scroll Progress Indicator** — Visual feedback for reading position
- **Intersection Observer Reveals** — Elements gracefully animate on scroll
- **Animated Number Counters** — Statistics count up when scrolled into view
- **Auto-Rotating Testimonials Slider** — Cycles every 8 seconds with manual controls
- **Interactive FAQ Accordion** — Smooth expand/collapse with animated toggles
- **Sticky Header** — Always-accessible navigation with backdrop blur
- **Back-to-Top Button** — Appears contextually with smooth scroll
- **Smooth Anchor Navigation** — Seamless in-page section scrolling

### 📱 Responsive & Accessible
- **Mobile-First Approach** — Fully responsive from 320px to 4K displays
- **RTL-Optimized** — Native right-to-left layout for Persian/Arabic audiences
- **Semantic HTML5** — Clean, maintainable, and SEO-friendly markup
- **Performance-Conscious** — No external frameworks, minimal dependencies
